# Anthropic Talking-Head Style

Apply a visual system while preserving the edit's factual content, timing, captions, and media choreography. Use with `$social-talking-head-video`, `$popout-talking-head-video`, or an existing HyperFrames composition.

Inspect [assets/example/anthropic-editorial.mp4](assets/example/anthropic-editorial.mp4) when a concrete reference for the complete warm editorial treatment is useful.

## Direction

Read [references/style-system.md](references/style-system.md). Use principles and tokens, not copied proprietary layouts or unsupported Anthropic branding.

Default to:

- warm ivory rather than pure white;
- charcoal rather than absolute black;
- terracotta for emphasis;
- muted editorial blue and botanical green as secondary accents;
- Poppins for display/UI and Lora for editorial supporting copy;
- flat cards, solid 2 px outlines, small corner radii, and offset print-like shadows;
- dotted paper grain and restrained light/dark scene alternation.

Avoid pills, glassmorphism, neon, generic gradients, excessive rounding, or decorative AI-status labels.

## Workflow

1. Inventory existing tokens, fonts, cards, caption treatments, and screenshots.
2. Preserve timing and media placement unless the user asks for an editorial restructure.
3. Replace the visual token layer first; then restyle cards, captions, and transitions.
4. Keep real product UI and logos accurate. Do not recolor source screenshots into false brand representations.
5. Use concise mask reveals, quick slides, scale pops, and restrained parallax. Favor hard-cut rhythm over ornamental transitions.
6. Inspect every light/dark handoff and caption contrast state.

Run HyperFrames checks and a phone-sized snapshot review before rendering.
